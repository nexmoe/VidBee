# FAQ

1. Use `search_transcript` or `read_transcript` to find questions and answers that the video actually states.
2. Write one question heading and a short answer per item, in the requested format.
3. If the transcript does not contain an answer, say so. Do not invent facts, timestamps, or screenshots.
